## 2. Instrucciones Generales para el/la Estudiante

* **Descripción general de la evaluación:** Cada evaluación parcial será una parte del examen transversal, dividiendo el caso en tres partes para las tres evaluaciones parciales. ## 3. Instrucciones Específicas de la Evaluación

### Situación Evaluativa 1: Entrega por Encargo (40%)

En la propuesta de actualización del proyecto, los estudiantes deben:

1. **Desarrollo Frontend con Framework JS:**
   * Incorporar un frontend basado en tecnología JS (React) para la construcción de una aplicación web, integrando elementos de responsividad.
   * Comprobar que el proyecto use un framework moderno de JavaScript y esté bien estructurado.
   * Gestionar correctamente propiedades (`props`) y estados (`state`) en los componentes React para asegurar su funcionamiento y personalización.
   * Asegurar el diseño responsivo adaptándose a diferentes pantallas mediante el uso de **Bootstrap**.
   * Documentar/explicar el uso del framework, el proceso de desarrollo de componentes, la gestión de estados/props y ejemplos de responsividad en diferentes dispositivos.

2. **Pruebas Unitarias para Frontend (Jasmine y Karma):**
   * Crear pruebas unitarias para componentes frontend abarcando diferentes casos de uso.
   * Verificar la lógica, el comportamiento del componente y la manipulación del DOM utilizando **Jasmine** y **Karma**.
   * Demostrar y explicar la creación de las pruebas unitarias y cómo verifican la calidad del código.

3. **Proceso de Testeo en el Desarrollo:**
   * Configurar las herramientas de testeo adecuadas asegurando la cobertura de las funcionalidades principales.
   * Explicar e implementar el proceso de testeo unitario: entorno de pruebas, escritura de pruebas, uso de **mocks** y análisis de resultados/cobertura.

#### Documentos Requeridos y Entregables por Grupo:
* **Enlace GitHub público** del proyecto frontend actualizado.
* **Proyecto frontend actualizado comprimido** (.zip / .rar).
* **Documento ERS** (Especificación de Requisitos del Software) con la propuesta personalizada terminada (última versión).
* **Documento de Cobertura de Testing** que valide el alcance de los elementos probados.

---

### Situación Evaluativa 2: Presentación (60%)

Durante la presentación, **cada estudiante** debe:

1. Exponer cómo se diseñó el proyecto utilizando un framework de JavaScript para frontend.
2. Mostrar el proceso de desarrollo de componentes React, gestionando propiedades y estados, e implementando diseño responsivo mediante Bootstrap.
3. Demostrar la creación de pruebas unitarias para componentes frontend con Jasmine y Karma.
4. Explicar cómo se implementó el proceso de testeo unitario (configuración, pruebas, mocks y análisis de resultados).
